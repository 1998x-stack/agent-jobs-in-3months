# C05 Concept Notes — 统计与置信区间

## 必懂术语

paired comparison / bootstrap / uncertainty

## 解释（学习时填写）

- What: 这个概念解决的具体问题是什么？
- Why: 如果没有它，Agent 会在哪种任务上失败？
- How: 最小的数据结构、输入、输出和状态变化是什么？
- Trade-off: 成本、速度、可靠性、风险如何权衡？

## 典型误区

- 演示代码成功 ≠ 生产环境语义正确。
- 模型返回内容 ≠ 可信指令或事实。
- 没有可复现测试就无法确认真正掌握。
