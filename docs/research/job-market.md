# Job Market Research Notes (Research Backlog)

This repository is organized around three recurring high-value skill clusters observed in Agent job descriptions:

1. Agent execution / context / tool systems.
2. Production reliability / identity / infrastructure.
3. Evaluation / optimization / post-training.

## Replicable research method

- Collect dated official postings with company, title, location, salary type and range.
- Separate base salary from total compensation; don't infer equity value.
- Normalize experience levels (Senior, Staff, Principal, Research).
- Map verbatim JD requirements to A/B/C skills and record ambiguities.
- Recheck links and close dates; hiring pages change.

## Source watchlist

- OpenAI careers, Anthropic careers, NVIDIA careers, Sierra careers, Decagon careers.
- Use snapshots or dated citations if claiming a specific salary.
