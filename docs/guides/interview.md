# Interview Preparation by Role

| Role | Project focus | Questions to be able to answer |
|---|---|---|
| Applied AI | P1 + P3 | Why tool calling? How do you judge actual task correctness? |
| Agent Platform | P1 + P2 | Why idempotency? How do leases recover from crashes? |
| Infrastructure / Staff | P2 + all | How do tenants, credentials, queues and SLOs compose? |
| Agent Research | P3 + P1 | What is the oracle? How do you avoid leakage? Which ablations matter? |
| Forward-Deployed | all + real domain | How do you translate workflows into measurable business value? |

STAR 面试案例模板：Context → Constraints → Decision → Implementation → Experiment → Failure → Result.
