# Definition of Done

## Atomic Skill DoD

- [ ] 能从第一性原理解释输入、输出、状态和错误语义
- [ ] `exercise.py` 有真实实现而不是仅删除 TODO
- [ ] `check_exercise.py` 包含边界测试和至少一个失败用例
- [ ] 与项目集成并有代码/测试证据

## Project DoD

- [ ] 可独立复现 Demo 和 tests
- [ ] 有架构图、模块职责和威胁边界
- [ ] 有任务评测和故障场景
- [ ] 有设计决策和已知限制
- [ ] 有 baseline/variant 结果与复现条件
- [ ] 不包含密钥或真实隐私数据
