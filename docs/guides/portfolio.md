# Portfolio Strategy

一份可用于高阶 Agent Engineer 面试的技术作品集，建议展示：

- **Architecture**：系统图、模型行为与系统权限边界。
- **Evidence**：可运行仓库、测试、回归记录、对比实验报告。
- **Reliability**：任务重复提交、Worker Crash、Lease 竞争等演练。
- **Safety**：越权、Prompt Injection、敏感操作的防护测试。
- **Evaluation**：版本化任务、Oracle、置信区间、失败分类。
- **Trade-offs**：为什么使用某框架、为何没有使用另一方案。

避免把玩具数据集上的 100% pass rate 写成真实 Agent Benchmark。
