# Glossary

- **Agent Harness**：管理模型循环、工具执行、状态及停止条件的执行框架。
- **Context Engineering**：为每轮决策选择和构造可用信息。
- **MCP**：标准化工具与上下文连接的协议；不是 Agent Planner。
- **Trajectory**：从动作到观察结果的一整条执行轨迹。
- **Oracle**：判定任务正确性的可信检验规则。
- **Idempotency**：重复执行请求不会产生额外的业务效果。
- **Lease / Fencing Token**：Worker 的限时租用与防陈旧提交手段。
- **HITL**：Human in the Loop，人类审查与批准关键动作。
- **Ablation**：控制其他因素，只改变一个组件的实验。
- **DPO**：利用偏好对直接优化模型偏好的训练目标。
- **SLO**：事先约定的可量化服务目标。
